# AGENTS.md — UVieKey

## Build & Test Commands

```bash
UVIE_RS_DIR=../uvie-rs ./build.sh && swift run   # Build + run dev instance
swift test                                        # Run the integration test suite (55 tests)
swift test --filter EngineTypingTests             # Engine typing behavior only
swift test --filter DispatcherTests               # Event-tap dispatch decisions only
```

`swift test` requires `Frameworks/libuvie.a` + `Frameworks/Sparkle.framework`
(generated by `build.sh`, or fetched via `scripts/fetch-uvie.sh`).

## Test Architecture

Tests simulate user keystrokes WITHOUT touching the host session:

- **EngineTypingTests** — feed character sequences through the real
  Swift↔Rust engine (EngineBridge FFI) and assert the reconstructed
  on-screen text. Expectations are locked to shipped v2.5.1 behavior
  (tones, w-modifiers, V-C-V, tone cancel, English dictionary override,
  VNI, simple Telex, modern orthography).
- **EngineStateTests** — backspace walk-back, commit, reset,
  introspection, and the FFI scratch-buffer reuse contract.
- **DispatcherTests** — drive `EventTap.handle()` with synthetic CGEvents
  and assert consume/pass-through decisions plus the injection plan.
  Includes the Cmd+Space → Spotlight refresh-budget regression test.
- **HelperTests** — key classification tables, selection shortcuts,
  auto-capitalize state machine, macro lookup.

### Test seams (production code)

Three protocols exist purely so tests can intercept side effects:

- `SyntheticOutputSink` — `EventTap.outputSink` (defaults to `self`);
  tests substitute `RecordingSink` so injections are recorded, not posted.
- `AXTextInjecting` — `EventTap.axInjector`; tests substitute
  `StubAXInjector` (no AX IPC).
- `AppContextDetecting` — `EventTap.appDetector`; tests substitute
  `StubAppDetector` with scripted `refreshBundleID()` results.

`makeEventTap()` (Tests/UVieKeyTests/TestSupport.swift) pins every
environment-dependent flag (auto-capitalize, macro toggle, app lists,
input method) so tests are deterministic regardless of the user's real
UserDefaults.

## Architecture

- `Sources/UVieKey/Core/` — hot path. `EventTap` (CGEventTap callback on
  the main runloop) dispatches to: CGEvent synthetic injection
  (`EventTap+SyntheticOutput`, posts to `.cgSessionEventTap`), AX text
  injection (`AXTextInjector`, used for Spotlight via `axApps`), or
  pass-through. The Vietnamese engine is Rust (`uvie-rs`, linked as
  `libuvie.a`) behind `EngineBridge` — diff API returns
  `(backspaces, suffix)` per keystroke.
- App classification (excluded/compound/chromium/ax/bypass) is cached in
  `EventTap` and refreshed on settings changes; the focused-app bundleID
  comes from `AppContextDetector` (NSWorkspace notifications) plus a
  budgeted AX refresh (`axRefreshAttempts`, 3 per trigger) for apps that
  never fire activation notifications (Spotlight).
- Settings flags read on the hot path are cached in `EventTap` /
  `MacroManager` / `Logger` and refreshed via
  `UserDefaults.didChangeNotification`. External `defaults write` needs an
  app restart; in-app toggles apply immediately.

## Notes

- Synthetic events are tagged with `eventSourceStateID = 0x55564945`
  ("UVIE") so the tap skips its own output.
- `warmUpSyntheticKeycodePath()` posts sacrificial events at tap creation:
  the first keycode post from a freshly-rebuilt binary can be dropped.
- AX injection trusts the `AXError` from the set call — never verify with a
  read-back (races Spotlight's live search → double input).
